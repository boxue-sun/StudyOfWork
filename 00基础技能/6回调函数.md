



回调函数

你现在的理解非常精准，可以直接作为笔记记下来：

1. **构造对象时填入一个函数** （这个函数就是回调，填啥都行，只要签名匹配）。
2. **对象内部有一个成员变量把它存起来** 。
3. **对象内部有一个触发函数（比如 `click()`）** 。
4. **当触发函数被调用时，它就去调用存好的回调函数** 。
5. **因此同一个类，填入不同的回调，就能实现不同的功能** （一个 click 多种表现）。

```C++
#include <iostream>
#include <functional>

// 按钮类
class Button {
public:
    // 定义回调类型：没有参数，没有返回值
    using ClickCallback = std::function<void()>;

    // 构造时，把回调存起来
    Button(ClickCallback cb) : cb_(cb) {}

    // 点击按钮时，调用回调
    void click() {
        if (cb_) {
            cb_();
        }
    }

private:
    ClickCallback cb_;  // 用来保存回调
};

// 一个普通函数
void sayHello() {
    std::cout << "你好，按钮被点了！" << std::endl;
}

int main() {
    // 用法1：传普通函数
    Button b1(sayHello);
    b1.click();   // 输出：你好，按钮被点了！

    // 用法2：传 Lambda
    Button b2([]() {
        std::cout << "按钮被点了，我要保存文件！" << std::endl;
    });
    b2.click();   // 输出：按钮被点了，我要保存文件！

    return 0;
}
```


为了让你更踏实，我把你的话稍微“翻译”成 C++ 术语，以后你看别人的代码或文档就能对上了：

| 你的大白话                             | C++ 专业术语                                                  |
| -------------------------------------- | ------------------------------------------------------------- |
| 填入的函数                             | 回调函数 / 可调用对象                                         |
| 填啥都行，只要是个函数                 | 必须匹配`std::function`规定的函数签名（参数和返回值要对上） |
| 对象里面还有一个调用这个回调函数的函数 | 事件触发函数（如`click()`、`onData()`、`Start()`）      |
| 构造完对象并填入回调函数               | 依赖注入 / 注册回调                                           |
| 用函数来调用回调函数                   | 触发事件 / 回调调用                                           |
| 一个 click 实现多个功能                | 多态 / 解耦 / 策略模式                                        |
