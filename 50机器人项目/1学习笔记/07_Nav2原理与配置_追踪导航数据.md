# 07 · Nav2 原理与配置：导航这套"现成工具箱"你怎么用

> 对应简历：**第 2 条**（定位与导航：集成 Nav2，配置 AMCL 定位、NavFn/Dijkstra 全局规划、DWB 局部跟踪、代价地图、Lifecycle 编排）。

## 0. 一句话先记住

**Nav2 是一套"导航乐高"：定位、规划、避障模块都现成，你做的是挑模块、填空参数、一键激活。** 你项目里所有导航参数都在一个文件：`diff_drive_robot/config/nav2_params.yaml`。

---

## 1. Nav2 的五个核心角色（对应你简历第 2 条）

| 角色 | 干嘛 | 你项目用的模块 | 代码落点 |
|---|---|---|---|
| **AMCL** | 在已知地图里实时定位（我在哪、朝哪） | `nav2_amcl::DifferentialMotionModel` | `nav2_params.yaml` 的 `amcl:` 段 |
| **全局规划** | 从当前点到目标点算一条全局路线 | `NavfnPlanner`（**Dijkstra**，`use_astar: false`） | `planner_server:` → `GridBased` |
| **局部规划** | 每刻按全局路线 + 实时障碍算速度指令，边走边避障 | `DWBLocalPlanner`（FollowPath） | `controller_server:` → `FollowPath` |
| **代价地图** | 把障碍画成"代价"，让路线绕开 | `obstacle_layer` + `inflation_layer` | `local_costmap:` / `global_costmap:` |
| **行为恢复** | 卡住时自旋/后退脱困 | spin / backup / wait 等 | `behavior_server:` |

## 2. 你调过的真实参数（挑重点记）

打开 `nav2_params.yaml`，这些是你**真改过/用到的**，面试能讲：

- **定位初始位姿**：`amcl.initial_pose: x=0, y=-3.5`（和 `robot.launch.py` 里 spawn 位姿一致，省得每次手动在 RViz 点"2D Pose Estimate"）。`set_initial_pose: true`。
- **速度上限**：`controller_server.FollowPath.max_vel_x: 0.26`（约 0.26 m/s，慢而稳），`max_vel_theta: 1.0`。
- **代价地图膨胀**：`inflation_radius: 0.55`、`cost_scaling_factor: 3.0`、`robot_radius: 0.22`——障碍周围 0.55 米内代价升高，车自然绕开。
- **全局规划器选 Dijkstra**：`NavfnPlanner.use_astar: false` → 所以是 **Dijkstra 最短路**，不是 A*。
- **目标容差**：`xy_goal_tolerance: 0.25`（到展点 25 厘米内就算到达）。
- **虚拟机特调**：`bt_navigator` 用"路径失效才重规划"的行为树（避免 1Hz 一直重规划打爆 CPU）；`lifecycle_manager` 的 `bond_timeout` 放宽到 15 秒（虚拟机心跳慢，防误判节点宕机）。

## 3. Lifecycle：为什么导航节点要先"激活"

Nav2 的节点是**生命周期节点（Lifecycle）**：刚起来是"未配置"状态，必须 `configure` 再 `activate` 才能真正工作。你不用手动点，靠 `lifecycle_manager` 一键按顺序激活（`navigation.launch.py` 第 79–88 行）：
```python
'node_names': ['controller_server', 'planner_server',
               'behavior_server', 'velocity_smoother', 'bt_navigator']
```
这就是为什么你启动导航时要等一会儿——它在按序激活这些节点。面试被问"Lifecycle 是什么"就答这个。

## 4. 动手体验：追踪导航在干啥

想看 Nav2 内部数据流，跑这个最小观察脚本（需要 ROS2 + 导航已起）：
```python
# inspect_nav.py —— 打印导航关键话题，看数据在流
import rclpy
from rclpy.node import Node
from nav_msgs.msg import Odometry
from sensor_msgs.msg import LaserScan
from nav_msgs.msg import Path

class Watch(Node):
    def __init__(self):
        super().__init__("watch")
        self.create_subscription(Odometry, "/amcl_pose", lambda m: print("位姿:", m.pose.pose.position), 10)
        self.create_subscription(LaserScan, "/scan", lambda m: print("激光点数:", len(m.ranges)), 10)
        self.create_subscription(Path, "/plan", lambda m: print("全局路径点:", len(m.poses)), 10)

rclpy.init(); rclpy.spin(Watch())
```
你会看到：位姿在变（AMCL 在定位）、激光不断来（避障输入）、发导航后 `/plan` 出现一串点（全局路线）。这就是 Nav2 在你项目里"活着的证据"。
