## 0. 一句话先记住

**ROS2 同一套概念，Python 用 `rclpy`、C++ 用 `rclcpp`。** 你已经懂了"节点/发布/订阅/定时器"这些思想（前面 8 篇都讲了），C++ 只是换种语法把同样的东西写出来。

---

## 1. Python 和 C++ 写法对照（你已经会思想，只差语法）

| 概念 | Python（你项目用的） | C++（本篇练的） |
|---|---|---|
| 初始化 | `rclpy.init()` | `rclcpp::init(argc, argv)` |
| 建节点 | `Node("xxx")` | `rclcpp::Node::make_shared("xxx")` |
| 发布者 | `create_publisher(...)` | `create_publisher<T>(...)` |
| 定时器 | `create_timer(0.2, cb)` | `create_wall_timer(200ms, cb)` |
| 跑循环 | `rclpy.spin(node)` | `rclcpp::spin(node)` |

思想完全一样，只是 C++ 要写类型、写 `main`、编译（用 CMake/COLCON）。

## 2. 一个最小 rclcpp 控制节点（练习用，非你项目代码）

下面这个 `move_to_x.cpp` 干的事：订阅里程计知道自己在哪，用定时器发速度指令，开到目标 x。思想对应你项目里"让车动起来"，但你是靠 Nav2 Action 干的，这里用 C++ 直接发 `cmd_vel` 演示：

```cpp
// move_to_x.cpp —— rclcpp 练习：开到目标 x 位置（教学，非项目主代码）
#include <rclcpp/rclcpp.hpp>
#include <nav_msgs/msg/odometry.hpp>
#include <geometry_msgs/msg/twist.hpp>

class MoveToX : public rclcpp::Node {
public:
    MoveToX(double target_x) : Node("move_to_x"), target_x_(target_x) {
        pub_ = create_publisher<geometry_msgs::msg::Twist>("/cmd_vel", 10);
        sub_ = create_subscription<nav_msgs::msg::Odometry>(
            "/odom", 10, [this](nav_msgs::msg::Odometry::SharedPtr m) {
                double x = m->pose.pose.position.x;
                double err = target_x_ - x;               // 离目标还差多少
                auto twist = geometry_msgs::msg::Twist();
                twist.linear.x = std::clamp(err * 0.2, -0.2, 0.2);  // 简单比例控制
                pub_->publish(twist);
                if (std::abs(err) < 0.05)
                    RCLCPP_INFO(get_logger(), "到达目标 x=%.2f", target_x_);
            });
    }
private:
    double target_x_;
    rclcpp::Publisher<geometry_msgs::msg::Twist>::SharedPtr pub_;
    rclcpp::Subscription<nav_msgs::msg::Odometry>::SharedPtr sub_;
};

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    rclcpp::spin(std::make_shared<MoveToX>(2.0));   // 目标 x = 2.0 米
    rclcpp::shutdown();
    return 0;
}
```

要点：订阅 `/odom` → 算误差 → 发 `/cmd_vel`。和 Python 版思路一模一样，只是类型写全了。

## 3. C++ 节点怎么编译

C++ 不能像 Python 直接 `ros2 run` 脚本，要**编译**。你项目用的是 `ament_python`（Python 包），C++ 包用 `ament_cmake` + `CMakeLists.txt`。编译命令：
```bash
colcon build --packages-select 你的包名
source install/setup.bash
ros2 run 你的包名 move_to_x
```
（`CMakeLists.txt` 里要 `find_package(rclcpp)`、声明可执行文件、做 `ament_target_dependencies`。）
