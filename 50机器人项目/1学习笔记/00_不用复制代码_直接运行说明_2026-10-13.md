## 现在学第二课：先体验 Action 通信

两个 Ubuntu 终端各输入一条，不用再手动 source、设置通信分组或构建：

```bash
# 终端 A：保持运行
bash ~/ros2_learning_ws/run_course.sh 2 server
```

```bash
# 终端 B：发送一个任务，观察接受、反馈和成功
bash ~/ros2_learning_ws/run_course.sh 2 client
```

继续在 B 一次运行一条，等上一条结束：

```bash
bash ~/ros2_learning_ws/run_course.sh 2 cancel
bash ~/ros2_learning_ws/run_course.sh 2 reject
bash ~/ros2_learning_ws/run_course.sh 2 fail
```

这部分对应第二课第 14 节。**它是模拟导航服务端，没有驱动 Gazebo 小车**，但 Action 接受、反馈、结果和取消都通过实际 ROS2 接口通信。

真实 Nav2 演示仍按第二课第 6、7 步操作：启动原项目，停止自动导览，使用 ROS_DOMAIN_ID=0 和 use_sim_time。不要把测试的 99/-99 坐标发给真实 Nav2。

## 现在学第三课：一次查询、一次答复

先退出第二课服务端 A，再分别输入：

```bash
# 终端 A：保持运行
bash ~/ros2_learning_ws/run_course.sh 3 server
```

```bash
# 终端 B：查询当前状态，打印一次后结束

```
