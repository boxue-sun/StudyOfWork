# 第四课：TF 坐标变换——机器人“前方一米”在地图哪里？

终端即可完成本课。需要 ROS2 Jazzy、`tf2_ros` 和 `geometry_msgs`；图形显示是最后的可选体验。

## 0．先用一个具体例子理解

机器人在地图的位置是 `(2, 1)`，朝向地图正 y 方向。机器人自己的“前方一米”用自身坐标表示为 `(1, 0)`，但在地图上是 `(2, 2)`。

为什么不是 `(3, 1)`？因为机器人已经转了 90 度，它的前方与地图的 x 轴方向不同。

**坐标系是“用谁的原点和方向描述位置”。TF 保存不同坐标系之间的位置与朝向关系。** 它本身不会定位，也不会产生机器人运动；关系必须由程序提供。

我们建立两个教学坐标系：`lesson_map → lesson_base`。不使用原项目的同名坐标系，避免混淆。

## 2．创建广播节点

```bash
nano lesson_tf_demo/frame_broadcaster.py
```

复制完整代码并保存：

```python
import math

import rclpy
from rclpy.node import Node
from geometry_msgs.msg import TransformStamped
from tf2_ros.static_transform_broadcaster import StaticTransformBroadcaster


class FrameBroadcaster(Node):
    def __init__(self):
        super().__init__('lesson_frame_broadcaster')
        self.broadcaster = StaticTransformBroadcaster(self)
        yaw = self.declare_parameter('yaw', math.pi / 2.0).value
        if not math.isfinite(yaw):
            raise ValueError('yaw must be finite')
        transform = TransformStamped()
        transform.header.stamp = self.get_clock().now().to_msg()
        transform.header.frame_id = 'lesson_map'
        transform.child_frame_id = 'lesson_base'
        transform.transform.translation.x = 2.0
        transform.transform.translation.y = 1.0
        transform.transform.rotation.z = math.sin(yaw / 2.0)
        transform.transform.rotation.w = math.cos(yaw / 2.0)
        self.broadcaster.sendTransform(transform)
        self.get_logger().info(f'TF_READY: robot at (2, 1), yaw={yaw:.3f}')


def main(args=None):
    rclpy.init(args=args)
    node = FrameBroadcaster()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        if rclpy.ok():
            rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## 3．创建查询节点

```bash
nano lesson_tf_demo/frame_listener.py
```

复制保存：

```python
import math

import rclpy
from rclpy.node import Node
from rclpy.time import Time
from tf2_ros import TransformException
from tf2_ros.buffer import Buffer
from tf2_ros.transform_listener import TransformListener


class FrameListener(Node):
    def __init__(self):
        super().__init__('lesson_frame_listener')
        self.buffer = Buffer()
        self.listener = TransformListener(self.buffer, self)
        self.timer = self.create_timer(1.0, self.on_timer)

    def on_timer(self):
        try:
            transform = self.buffer.lookup_transform('lesson_map', 'lesson_base', Time())
        except TransformException:
            self.get_logger().info('WAIT_TF: waiting for lesson_map <- lesson_base')
            return
        # 本课只有平面绕 z 轴旋转，计算机器人前方 1 米的地图坐标。
        q = transform.transform.rotation
        yaw = math.atan2(2.0 * (q.w * q.z + q.x * q.y),
                         1.0 - 2.0 * (q.y * q.y + q.z * q.z))
        origin = transform.transform.translation
        point_x = origin.x + math.cos(yaw)
        point_y = origin.y + math.sin(yaw)
        self.get_logger().info(
            f'POINT_IN_MAP: ({point_x:.3f}, {point_y:.3f}); yaw={yaw:.3f}')


def main(args=None):
    rclpy.init(args=args)
    node = FrameListener()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        if rclpy.ok():
            rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## 6．最关键的代码

广播端：

```python
transform.header.frame_id = 'lesson_map'
transform.child_frame_id = 'lesson_base'
transform.transform.translation.x = 2.0
transform.transform.translation.y = 1.0
```

意思是：`lesson_base` 原点在 `lesson_map` 中位于 `(2,1)`；后面的四元数填机器人坐标轴相对地图转了多少。

查询端：

```python
transform = self.buffer.lookup_transform('lesson_map', 'lesson_base', Time())
```

参数依次为 **目标坐标系、源坐标系、时刻**。得到的是“把 lesson_base 中的坐标表达成 lesson_map 中坐标”所需的关系。`Time()` 的零时刻在这里表示取最新可用变换。

`Buffer` 保存收到的坐标关系；`TransformListener` 接收 TF 并放进去。程序刚启动尚未收到数据时抛出 `TransformException`，回调捕获后下次再试。

本课点 `(1,0)` 经过平面旋转和平移：

```text
地图 x = 机器人原点 x + cos(yaw) × 1
地图 y = 机器人原点 y + sin(yaw) × 1
```

这是为学习写出的特殊平面情况。一般三维点变换要处理完整旋转和位移，不应把这两个公式当成通用 TF 实现。

## 7．改朝向，先预测再验证

先退出 A、B，重新运行 A：

```bash
ros2 run lesson_tf_demo frame_broadcaster --ros-args -p yaw:=0.0
```

重新启动 B。应变为：

```text
POINT_IN_MAP: (3.000, 1.000); yaw=0.000
```

为什么也重启 B？本课用静态关系做实验，重新启动监听器让你避免保留上一次关系的缓存，清楚观察新的一组数据。

## 9．对应你的原项目

| TF 关系 | 谁提供 | 作用 |
|---|---|---|
| `map → odom` | AMCL | 把里程计坐标与地图定位对应起来 |
| `odom → base_link` | 当前项目的 Gazebo OdometryPublisher，经桥接 | 小车相对里程计原点的姿态 |
| `base_link → laser_frame` 等 | robot_state_publisher | 传感器安装在车体哪里 |

Nav2 需要知道雷达数据在哪个位置测到、小车目前在地图哪里，因此要结合 TF。不能只有 `/scan` 和目的地数字，却不管坐标关系。

本课没有实现 AMCL，也没有测量真实位置；先掌握“关系谁发布、谁查询、坐标怎么变”。
