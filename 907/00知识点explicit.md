`explicit`用来修饰构造函数的 也只能修饰构造函数；
**`explicit` 是 C++ 中的一个关键字，用于修饰单参数构造函数（以及 C++11 起的类型转换运算符），作用是禁止编译器进行隐式类型转换，确保对象只能通过显式的直接初始化或强制类型转换来创建，从而避免因意外的类型转换而导致的歧义和错误，提高代码的安全性、可读性和可维护性。**


作用是避免 隐式类型的转换 必须按照规定的类型 **显式调用构造函数或转换运算符**

```C++
class MyClass {
public:
    explicit MyClass(int x) { }
};

MyClass obj1 = 10;    // ❌ 错误！不允许隐式转换
MyClass obj2(10);     // ✅ 正确！显式构造
MyClass obj3 = MyClass(10);  // ✅ 正确！显式构造
```

#### ③ 防止多参数构造函数的单参数隐式转换

```C++
class Point {
public:
    // 两个参数，但第二个有默认值
    explicit Point(int x, int y = 0) { }  
};

Point p1 = 10;     // ❌ 错误！不会隐式调用 Point(10, 0)
Point p2(10);      // ✅ 正确！显式调用 Point(10, 0)
```




4. 什么时候应该用 explicit？
   场景	是否使用	原因
   构造函数只有一个参数	✅ 强烈建议	最容易发生隐式转换
   多个参数但后面有默认值	✅ 建议	本质还是单参数构造
   转换是自然、无歧义的（如 int → double）	❌ 不需要	如复数类的 Complex(double)
   转换是反直觉的（如 int → MyString）	✅ 必须	防止意外
   拷贝/移动构造函数	❌ 不需要	这是标准的类型构造方式
