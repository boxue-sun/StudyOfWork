一、技术面

	1.1禁止拷贝

	dector探测器都是一个基类写的。一个类禁止拷贝的方法 是可以继承一个类，这个类里面就定义不可拷贝。如下：

```C++
namespace afl {

class Noncopyable {
public:
    Noncopyable(const Noncopyable&) = delete;//括号拷贝禁止 默认拷贝构造禁止
    void operator=(const Noncopyable&) = delete;//赋值拷贝禁止

protected:
    Noncopyable() = default;
    ~Noncopyable() = default;
};

}
```

	那为什么要禁止拷贝呢？

	如果允许拷贝，按值传递时只会拷贝基类那一部分，派生类特有的状态和虚函数行为就丢了，多态直接失效，这就是对象切片。所以继承 `Noncopyable` 就是提前禁止拷贝，逼你只能用指针、引用或 `unique_ptr` 来用它，保证多态和唯一状态不被破坏；真要复制，就显式提供 `clone()`。

	1.3 StopLineCrossingTracker停止线判断是否过线类

	**一个带状态的多帧停止线穿越跟踪器。**
	它保存每个目标上一帧的位置，逐帧判断目标从上一帧到当前帧的移动线段是否穿过停止线；如果穿过，并且目标之前没被记录过、又通过了质量门控，就认为它刚过线，加入返回结果。同时它还会清理过期轨迹、防止重复上报。

	问题1：怎么保存的

			遍历每帧中的目标 然后存入`_prev_positions`中。

	问题2：怎么判断是否过线

		答：穿过线＋之前没上报过＋通过质量门控。过线逻辑算法就是：先算出两条无限直线的交叉点；再检查这个交叉点是不是同时落在两条线段身上；都在 → 相交；有一个不在 → 不相交。

	问题4：质量门控是啥

		答：对于行人或者非机动车来说 因为它们存在速度慢、位移小的原因，而且可能和停止线平行过马路的情况。避免误判 加上一个质量门控。

		质量门控：如果是机动车 直接true；否则，看一下两帧的距离，如果小于0.5视为抖动，不通过，返回false；同时，构造停止线的法向量（逆转90度方向），过线的方向应该和法向量近似平行。判断和法向量的方法 是计算余弦值，cos ≥ 0.5 ⟺ 夹角 ≤ 60° → 方向足够垂直于停止线，通过；cos < 0.5 ⟺ 夹角 > 60° → 太接近平行于停止线，判为"擦过"而非穿越，否决。

	问题5：如何清理＋防止重复上报

		答：遍历`_prev_positions`里面的目标。当前时间戳-最后一次出现的时间>我们设定好的时间 就说明这个目标的消失时间太久了。就清理，容器`_prev_positions` 存的就是 **每个目标上一次被处理时的状态** （位置 + 时间戳）。直接_prev_positions.earese()清除该目标。

		为什么要防止重复上报？

			答：穿越是瞬时事件，但判定靠"两帧连线相交"，而抖动/来回会让同一物理穿越在连续多帧反复满足相交条件，重复上报会污染下游的计数、违章、信号联动。所以要防止重复上报。

		怎么防止重复上报？

			答：_crossed_ids记录的是穿越的车辆的id。 所以防止重复上报就是 先判断这个id有没有存在 没有存在就存入。

流程：

每来一帧 PerceptionResult:
  ├─ 1. 清理过期目标（>10s 没出现的从 _prev_positions 删掉）
  ├─ 2. 遍历本帧每个目标 obj:
  │     ├─ 分类过滤（NONE 的直接跳过）
  │     ├─ 判断 strict（行人/非机动车走严格门控）
  │     ├─ 如果 _prev_positions 里有 obj.id：
  │     │     ├─ 取上一帧位置 prev，连成线段 movement(prev → curr)
  │     │     ├─ 三个条件同时满足才算穿越：
  │     │     │     ① _stop_line.has_intersect(movement)   ← 你说的"连线相交"
  │     │     │     ② !_crossed_ids.count(obj.id)          ← 没上报过
  │     │     │     ③ passes_quality_gate(...)             ← 质量门控
  │     │     └─ 满足 → 加入 crossed、记入 _crossed_ids
  │     └─ 无论新旧，都写回 _prev_positions[id] = {curr, now}
  └─ 3. 返回 crossed
